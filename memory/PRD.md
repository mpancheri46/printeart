# Pixel Memories - Landing Page PRD

## Problema Original
Usuario desarrollando página web para Pixel Memories - negocio de fotolibros, polaroids y regalos personalizados en Argentina. Quería mejorar y pulir la página existente usando HTML, CSS y JavaScript.

## User Personas
- **Clientes particulares**: Personas que quieren imprimir recuerdos familiares, casamientos, bebés
- **Clientes corporativos**: Empresas buscando merchandising y regalos personalizados

## Core Requirements
- Landing page moderna y responsive
- Header con navegación
- Hero section con imagen de productos
- Sección de productos destacados
- Proceso de compra (Cómo Funciona)
- Testimonios de clientes
- Footer completo con contacto
- Integración WhatsApp
